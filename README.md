# Celestial Client (Fabric 26.3)

Celestial is a client-side utility mod with a custom dark interface, configurable themes, profiles, HUD counters, and optional utility modules.

## Build with GitHub Actions

1. Upload the contents of this project folder to the root of a GitHub repository.
2. Open **Actions** and select the **build** workflow.
3. Run it (or push a commit to trigger it).
4. Download the `celestial-client-26.3` artifact.
5. Put the remapped mod JAR from the artifact into your Fabric `mods` folder.

The workflow installs Java 25 and Gradle itself, so a Gradle wrapper is not required.

## In game

- Open the client interface with **Right Shift**.
- Change modules, HUD options, profiles, and themes in the interface.
- The menu is designed as a non-pausing overlay.

## Compatibility

Minecraft 26.3, Fabric Loader 0.20.1, Java 25.
